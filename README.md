# Mishi Tareas

Una lista de tareas con un mishi que te acompaña y cambia de ánimo según tu avance. Todo se guarda en tu navegador.

Hecho por mi-fabrica, una fábrica de software con agentes.

## Verlo

- En línea: GitHub Pages (Settings → Pages del repo).
- En tu máquina: `python3 -m http.server 8000` en esta carpeta y abre http://localhost:8000
  (los módulos de JavaScript no cargan abriendo el archivo directamente).

## Tests

```bash
node --test
```
